# README.md

## 📌 프로젝트 개요

이 프로젝트는 **LSTM 기반 시계열 예측 모델**을 사용하여 환자별 퀴즈 풀이
기록(`quiz_logs.csv`)으로부터 향후 **10일간 정답률**과 **월 평균
정답률**을 예측합니다.

------------------------------------------------------------------------

## 📂 파일 구조

    ├── quiz_logs.csv         # 입력 데이터 (환자별 퀴즈 로그)
    ├── quiz_froglstm.py               # 전체 파이프라인 코드
    ├── best_model_10d.pt     # 학습된 LSTM 모델 가중치 (훈련 후 생성)
    ├── predictions.csv       # 예측 결과 (출력)
    ├── training_curves.png   # 학습 과정 시각화
    └── README.md             # 설명 문서

------------------------------------------------------------------------

## 📊 입력 데이터 구조 (`quiz_logs.csv`)

CSV는 최소한 아래와 같은 컬럼들을 포함해야 합니다:

  컬럼명              설명
  ------------------- ---------------------------------
  patient_id          환자 ID
  question_id         문제 ID
  question_topic      문제 주제
  is_correct          정답 여부 (0 또는 1)
  response_time_sec   응답 시간 (초 단위)
  created_at          풀이 시각 (YYYY-MM-DD HH:mm:ss)

------------------------------------------------------------------------

## ⚙️ 주요 파라미터

코드 상단에서 하이퍼파라미터를 설정할 수 있습니다:

``` python
WINDOW      = 45      # 입력 시퀀스 길이 (45일)
HORIZON     = 10      # 예측 기간 (10일)
BATCH_SIZE  = 32
EPOCHS      = 50
LR          = 1e-3
TRAIN_RATIO = 0.7     # 학습 데이터 비율
EARLY_STOP  = 5       # Early Stopping patience
```

## 📑 예측 결과 (`predictions.csv`)

출력되는 CSV는 다음과 같은 구조를 가집니다:

  -----------------------------------------------------------------------------------------------------------------
  patient_id   input_start   input_end    pred_start   pred_end     pred_day1   ...   pred_day10   pred_month_avg
  ------------ ------------- ------------ ------------ ------------ ----------- ----- ------------ ----------------
  U001         2025-01-01    2025-02-14   2025-02-15   2025-02-24   0.62        ...   0.65         0.64

  -----------------------------------------------------------------------------------------------------------------

-   **pred_day1 \~ pred_day10** : 향후 10일간 정답률 예측\
-   **pred_month_avg** : 예측 시작일 기준 월평균 정답률

------------------------------------------------------------------------

## 📈 학습 과정 시각화

-   `training_curves.png` 파일에 **Train Loss, Validation MSE,
    Validation MAE**가 저장됩니다.\
-   Early Stopping이 적용되어 과적합을 방지합니다.

------------------------------------------------------------------------

## 🔮 모델 설명

-   입력: 최근 `WINDOW`일(45일)의 정답률 및 평균 응답 시간\
-   출력: 향후 `HORIZON`일(10일)의 일별 정답률 + 월평균 정답률\
-   모델 구조:
    -   **LSTM** (2층, hidden size=64, dropout=0.2)\
    -   **FC Layer** : `(hidden → hidden/2 → HORIZON+1)`\
-   손실 함수: **MSELoss**\
-   최적화 알고리즘: **Adam**

------------------------------------------------------------------------

## ✅ 요약

이 프로젝트는 **교육 데이터 로그 기반의 정답률 예측**을 수행합니다.\
- 환자별 시계열 데이터를 **선형 보간**으로 보정\
- **LSTM** 모델로 미래 정답률 예측\
- **결과를 CSV로 저장** 및 **학습 곡선 시각화**
